# Дизайн-система ИС «Заречное»

**Статус:** Фаза 0 — аудит и план. Правки ещё не применены; точка останова перед Фазой 1.
**Область действия:** `ui/public/index.html`, `ui/public/styles.css`, `ui/public/app.js`.
**Регулирует:** весь визуальный язык приложения. Бизнес-логика, API, RU/EN-словари, RBAC и инфраструктура не являются предметом этого документа.

---

## 1. Направление: «полевая ведомость»

Айдентика задана в шапке `styles.css:1-8` и подтверждена скриншотами «до»: тёплая песочная бумага, глубокий лесной зелёный, один янтарный акцент, волосяные линейки, сдержанная типографика. Это **не** «спокойный» корпоративный интерфейс: характер приложения — в бумажной фактуре, корешке под шапкой, крупном приветствии кабинета, карте и скетчах пустых состояний. Задача — убрать шум и несогласованность, **не** выхолостить характер.

Принципы:
1. Один акцент (янтарный) на экран — только для действия/внимания.
2. Зелёный — цвет бренда, ссылок и успеха; не фон каждого блока.
3. Линии — волосяные, 1px; границы инпутов контрастные (≥3:1), остальные линии могут быть декоративными.
4. Плотность «ведомости»: строка таблицы ≥36px, tabular-nums в числах.
5. Никаких новых декоративных эффектов. Новый элемент должен быть либо токеном, либо компонентом, либо обоснованным исключением.

## 4. Шкалы

- **Отступы:** сетка 8px; `--u-1…--u-10` = 8…80px. `--u` — deprecated алиас, удалить точечно после grep.
- **Радиусы:** `--r-sm` 4, `--r` 8, `--r-lg` 12, `--r-pill` 999. Card → 8, dialog → 12, chip → pill.
- **Типографика:** system stack (без внешних шрифтов). 12 / 13 / 15 / 16 / 18 / 22 / 28 / 36. h1 28, h2 22, h3 18; line-height 1.2 заголовков, 1.5 текста. Числа в таблицах — `tabular-nums`; mono только для id/кодов.
- **Тени (3 уровня):** paper-1 `0 1px 2px`, paper-2 `0 2px 8px + 0 8px 24px`, paper-3 `0 12px 40px + 0 2px 8px`. В тёмной теме — только чёрные, без цветных свечений.
- **Движение:** `--dur-fast` 120ms, `--dur` 200ms, `--dur-slow` 360ms; entrance — ease-out; анимировать только `transform`/`opacity`; bounce/elastic запрещены.

## 5. Правила компонентов

- **Кнопки:** одна primary на экран/модалку; высоты 28 / 36 / 44 из шкалы; secondary/ghost/danger консистентны; focus-visible ≥3:1; текст на primary — через `--on-primary`, без theme-hack.
- **Формы:** label сверху; placeholder не заменяет label; ошибка текстом под полем + `aria-invalid` (сохранить); одна система required-звёздочки; sentence-case подписей.
- **Таблицы:** sticky thead сохранить; сортировка с индикатором; действия в отдельной колонке без «прыжка»; строка ≥36px; зебра едва заметна.
- **Тосты/бейджи/чипы:** цвет = смысл (успех/ошибка/инфо), не декор; бейджи без смысла удаляются.
- **Модалки/палитра/справка:** фокус-ловушка, `inert` и возврат фокуса на триггер — сохранить; Esc закрывает; кликабельная область крестиков ≥24×24.
- **Пустые состояния:** скетч + одна фраза + действие. Ошибки: что случилось + что делать, без кодов и жаргона.
- **Pager / hotkeys-bar / stat-strip:** выравнивание по 8px сетке и токенам.

## 6. Правила тем (механика)

1. `data-theme` на `<html>` (сейчас на `<body>` — `app.js:1836`; перенести без потери ключа `zarechnoe.theme`, `app.js:18`).
2. Инлайн-скрипт в `<head>` **до** `<link rel="stylesheet">`: `localStorage['zarechnoe.theme']` → иначе `prefers-color-scheme`. Анти-FOUC.
3. `color-scheme: light / dark` на `:root`; `<meta name="theme-color">` обновляется при переключении.
4. Слушатель `matchMedia('(prefers-color-scheme: dark)')`, если пользователь не делал ручного выбора.
5. Переключатель не должен мигать при перезагрузке; `applyTheme()` не должна перезаписывать сохранённый выбор при загрузке (сейчас пишет всегда — `app.js:1840`).
6. Existing choice `zarechnoe.theme` / `zarechnoe.lang` сохраняется **обязательно**.

### Карта и графики
- Тёмная тема: затемнение OSM-тайлов CSS-фильтром на `.leaflet-tile-pane` (`invert + hue-rotate + brightness`) или CARTO dark с сохранением атрибуции. Контуры пастбищ и попапы — читаемыми в обеих темах.
- Canvas (donut/bars/отчёты): цвета из `getComputedStyle` семантических токенов, перерисовка на `themechange`; оси/легенды ≥4.5:1; серии — палитра Okabe–Ito как ориентир, без «радуги».

## 9. Иконки

- Спрайт: 24×24, `fill:none`, `stroke:currentColor`, `stroke-width:2`, round cap/join. Размеры 16 (кнопки) / 20 (меню) / 24 (крупные); на 16px — `vector-effect: non-scaling-stroke` или мелкий вариант.
- «Зарисовки» (корова, колос) — заменить аккуратными аналогамиTabler (MIT) / Lucide (ISC), **вендорить локально** + `LICENSE`. Скетчи пустых состояний — оставить как бренд, привести к единой манере.
- Логотип-колос (`index.html:90-95,145-149`): перерисовать чище, цвета через `fill="var(--…)"`, проверить в обеих темах.
- Каждая иконка: `aria-hidden="true"` + подпись/aria-label у кнопки; кликабельная область ≥24×24.

## 10. Доступность и движение

- `@media (prefers-reduced-motion: reduce)`: отключить параллакс, счётчики, reveal, shimmer, view transitions; состояния — мгновенно.
- Контент видим по умолчанию; reveal только добавляет эффект (не регрессировать `bb0ebd9`).
- Skip-link работает; h1→h2→h3 без пропусков; весь путь логин → раздел → модалка → сохранение без мыши.

### 11.5 Известные ограничения

- Leaflet 1.9.4 вендорирован локально (`ui/public/vendor/leaflet/`, BSD-2-Clause, `LICENSE`); внешних CDN в UI нет. Тайлы OSM по-прежнему требуют сети: при `tileerror` показывается плашка «Тайлы карты недоступны», контуры из API остаются, атрибуция OSM сохраняется.
- На проде в `localStorage` браузера уже сохранена тема `dark`; «светлые» скриншоты «до» получены принудительным переключением.
- `applyTheme()` сейчас пишет тему в `localStorage` при каждой загрузке — при отсутствии сохранённого выбора это создаст ключ до того, как заработает системное предпочтение (исправляется в B5).
- Словари RU/EN и API-контракты не трогаются; копирайтинг-правки — только явный слоп в UI-строках.
