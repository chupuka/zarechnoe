# Таблицы тест-кейсов ИС «Заречное» (вариант 11)

**Объект тестирования:** информационная система учёта фермерского хозяйства «Заречное».
**Стек:** PostgreSQL 16 + PostGIS 3.4, Node.js 22 + Express, REST API `/api/v1`.
**Состояние стенда:** Недели 1–6 (56 таблиц, 12 доменов, 93 FK, 7 VIEW, 6 триггеров, 12 процедур/функций, демо-данные: 100 голов, ~9,3 тыс. задач, ~29,7 тыс. движений склада, 2 года истории); подключены `/api/v1/admin/*` и `/api/v1/tech/*`.

**Базовый URL:** `http://127.0.0.1:3000/api/v1`.
**Заголовки:** `Content-Type: application/json`, `Authorization: Bearer <токен>`, для технических ролей дополнительно `X-Override-Reason: <причина>`.
**Демо-пользователи (пароль `demo1234`):** `director` (DIRECTOR), `superuser` (SUPERUSER, TECHNICAL), `dba` (DBA, TECHNICAL), `vet` (VET), `foreman` (FOREMAN), `storekeeper` (STOREKEEPER).
**Роли:** DIRECTOR, SUPERUSER, DBA, VET, FOREMAN, STOREKEEPER.
**Права:** `animal:*`, `group:*`, `stock:*`, `task:*`, `pasture:*`, `user:*`, `settings:*`, `audit:READ`, `tech:*`, `catalog:*`, `employee:*`, `backup:*`, `purchase:*`, `health:*`, `disposal:*`, `ration:*`, `product:*`, `report:READ`, `export:EXEC`, `period:*`.

**Идентификатор кейса:** `TC-<ГРУППА>-<NN>`, например `TC-AUTH-01` соответствует коду `AUTH-01` из перечня групп. Всего 64 кейса в 12 группах.
**Статусы:** `PASS` / `FAIL` / `—` (кейс не выполнялся). До прогона столбец «Фактический результат» заполнен «—», статус «—».
**Маппинг ошибок** (`middleware/errors.js`): `P0001` → 400 `business_rule`, `23505` → 409 `conflict`, `23503` → 400 `foreign_key`, `23514` → 400 `check_violation`, `22P02/22007/22008` → 400 `invalid_input`, `42P01` → 500. Явные `err.status`: 401, 403, 404, 423, 428.
**Слой валидации:** `src/validation.js` (`validate`, `parsePaging`, `parseSort`); все write-операции — через `withTransaction`.
