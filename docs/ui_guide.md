# Руководство пользователя веб-интерфейса

> ИС «Заречное», вариант 11, UI v1.4.0. Интерфейс: <http://localhost:3000/app/>.
> Справочник API: <http://localhost:3000/api/v1/docs>.

## 1. Вход и общая раскладка

1. Введите логин и пароль (демо-пароль для всех ролей — `demo1234`).
2. После входа открывается **«Главная»** (`#/home`) — точка входа для всех ролей.
   На ней показаны приветствие, роль, сводный показатель по доступным разделам и
   кнопки быстрого перехода только туда, куда есть право.
3. Слева — боковое меню. Пункты без права автоматически скрываются.
4. Над таблицей — **плашка показателей раздела**, под заголовком — **фильтры
   по полям**, внизу — пагинация с выбором количества записей.

Технические роли (`superuser`, `dba`) при любой записи обязаны указать причину
`X-Override-Reason` — в модалке появляется отдельное поле. Причина попадает
в аудит с `is_elevated = TRUE`.

## 2. Что изменилось в интерфейсе

| Было | Стало |
|---|---|
| Глобальная плашка поиска «на все случаи» на каждой странице | Фильтры по конкретным полям у заголовка раздела (`#page-tools`) |
| Выбор «25 записей» рядом с поиском | Выбор 25/50/100 в нижней пагинации (`#pager-limit`) |
| Показатели только на дашборде | Плашка `/stats/:section` на каждой странице |
| Резервные копии и восстановления на разных экранах + поиск по журналу | Одна страница «Резервные копии»: текущая копия, период, история, восстановления |
| Метрики — сырые числа | Вердикт «БД отвечает быстро / нужна оптимизация» |
| У пользователей — только сброс пароля | Блокировка, разблокировка, пароль, сессии, права роли |
| У сотрудников — только реестр | ПДн, закрепления, увольнение, восстановление |
| У бригадира — таблица выпаса | Сводка: группы, непокрытые животные, «кто за кем смотрит» |

Экран освобождён: фильтры компактные, лишние поля не дублируются, пагинация
одна. Пустая плашка показателей скрывается автоматически (у роли нет прав).

## 3. Разделы и права

| Раздел | Что можно делать |
|---|---|
| **Обзор → Главная** | Сводка по роли, быстрые ссылки, тревожные показатели |
| Животные | Реестр, фильтр по статусу/группе/закреплению, смена статуса (в т.ч. `НА_ПРОДАЖЕ`, `ПРОДАН`), назначение сотрудников |
| Осмотры / Вакцинации | Те же списки с предустановленным статусом, смена статуса |
| Сотрудники | Фильтры по должности, активности, ПДн, закреплениям; карточка, ПДн (право `employee:PII`), закрепление, увольнение, восстановление |
| Склад | Партии/остатки (переключатель), приход, расход, списание, возврат |
| Задачи / наряды | Создание, назначение, выполнение, фильтр по исполнителю и статусу |
| Участки, Выпас | Карта OSM, перевод групп, сводка бригадира, закрепление сотрудника |
| Пользователи | Создание, смена роли, блокировка/разблокировка с причиной, генерация пароля, сессии и их отзыв |
| Роли и права | Матрица разрешений роли (у DBA бизнес-запись нельзя выдать) |
| Журнал аудита | Поиск, фильтр по пользователю/действию/дате/категории; отбор «Только нарушения (DENY)», «Просмотр ПДн», CSV |
| Резервные копии | Текущая копия, период, история, восстановления, скачивание файла |
| Скорость БД | Вердикт, перцентили, корзины, медленные запросы, состояние БД |
| Отчёты | Дашборд, себестоимость/FCR, здоровье стада, нагрузка на пастбища, задачи, оборот склада, график, CSV |

## 4. Работа с фильтрами

- Поиск (`q`) реагирует на ввод с задержкой 400 мс и по Enter.
- Селекты применяются сразу при изменении.
- Чекбоксы (`include_deleted`, `is_elevated`) работают как флаги.
- Кнопка **«Сбросить»** возвращает фильтры раздела в состояние по умолчанию
  (для «Осмотров» и «Вакцинаций» сохраняется предустановленный статус).
- Имена полей приводятся к API: `from` → `date_from`, `to` → `date_to`,
  `status` → `status` (для DBA-разделов — `state`).
- Размер страницы задаётся внизу и сохраняется при переключении страниц
  внутри раздела; при смене раздела сбрасывается на 25.

## 5. Персональные данные

- В реестре сотрудников видна только маска телефона (`phone_mask`) и признак
  «ПДн заполнены».
- Кнопка строки **«ПДн»** доступна по праву `employee:PII`: открывает все поля,
  данные приходят в расшифрованном виде **только** после проверки права;
  факт чтения записывается в аудит как `READ_PII` и виден в журнале
  (`Категория → Просмотр ПДн`).
- Ключ шифрования живёт только в окружении сервера (`PII_KEY`); в интерфейсе
  и в базе его нет.

## 6. Увольнение и закрепления

- Увольнение требует обязательной причины и даты. Последствия: закрепления за
  животными закрываются, связанные учётные записи блокируются, сессии отзываются.
- Восстановление возвращает сотрудника в active, причина также должна быть указана.
- Закрепление создаётся со строки животного или сотрудника; роль выбирается из
  `VET`, `HERDSMAN`, `FOREMAN`, `ZOOTECHNIK`. При выбытии животного
  (`ПРОДАН`, `ПАДЁЖ`, `ВЫБРАКОВАНО`) закрепления закрываются автоматически.

## 7. Бэкапы и скорость БД

- Страница «Резервные копии» не требует поиска: всё необходимое уже на экране.
  Настройки периода меняются на месте, плановую копию можно выполнить кнопкой.
- Файл копии скачивается кнопкой строки (Bearer-токен прилагается автоматически).
- Восстановление доступно по `backup:EXEC` и всегда требует причины.
- На странице «Скорость БД» зелёный вердикт означает «оптимизация не нужна»;
  жёлтый/красный — пора смотреть на самые медленные запросы и таблицы с seq scan.
  Пороги меняются администратором в `farm_settings`.

## 8. Горячие клавиши и палитра действий

Подсказка внизу экрана и справка (`?`) строятся **по правам текущей роли** —
в них нет действий, которые вам недоступны. Справка показывает название роли,
название каждой клавиши и полный список доступных операций с пояснениями.

| Клавиша | Действие |
|---|---|
| `Ctrl+K` | Палитра действий — поиск по всем доступным вам операциям |
| `?` | Справка по горячим клавишам и возможностям вашей роли |
| `N` | Создать запись текущего раздела: у бригадира на «Животных» — новое животное; у DBA — палитра со «Создать: Пользователи» |
| `E` | Изменить выбранную строку или открыть палитру действий «Изменить…» |
| `B` | Заблокировать пользователя: сразу второй шаг с поиском по логину/ФИО |
| `/` | Фокус на поле поиска текущего раздела |
| `R` | Обновить данные |
| `I` / `O` / `W` | Приход / расход / списание на складе (только при правах склада) |
| `A` | Назначить / закрепить / перевести группу |
| `D` | Выполнить задачу |
| `Esc` | Закрыть окно/карту/палитру |
| `G`, затем `A`/`S`/`D` | Быстрый переход: животные / склад / дашборд |

### Палитра действий

Открывается кнопкой «Действия» в шапке или в футере, либо `Ctrl+K`.
Это универсальный поиск по операциям, которые разрешены вашей роли:

- **На этой странице** — создание, операции тулбара, действия с выбранной строкой.
- **Создать в другом разделе** — перейти и сразу открыть форму (животные,
  сотрудники, пользователи, участки, группы, задачи).
- **Операции разделов** — приход/расход/возврат склада, перевод группы на выпас,
  назначение и выполнение задач из любого экрана.
- **Пользователи** — блокировка, разблокировка, генерация пароля, сессии, редактирование.
- **Сотрудники / Животные** — ПДн, увольнение, закрепления, смена статуса.
- **Техника** — резервная копия, восстановление, сброс метрик.

Если операция требует записи, после её выбора открывается **второй шаг**:
поиск по логину, ФИО, инв. номеру или номеру копии. Выбор строки сразу
открывает нужную форму. Навигация по списку — `↑`/`Enter` или клик.

Кнопка «Создать» в заголовке показывает конкретное действие (`+ Животные [N]`),
а не абстрактное «Новая запись». Если у роли нет права создавать в текущем
разделе, кнопка скрывается, но остаётся доступной в палитре для других разделов.

## 9. Как устроено (для разработчика)

- Все страницы описываются одним объектом `PAGES` в `ui/public/app.js`:
  `endpoint`, `perm`, `columns`, `filters`, `toolbar`, `rowActions`,
  `statSection`, `noFilters`, `noPager`. Разметка — в `index.html`
  (`#stat-strip`, `#page-tools`, `#view`, `#pager`), стили — в `styles.css`.
- Фильтры собираются декларативными хелперами `fSel/fSearch/fDate/fCheck/fPairs`;
  ключ `query` в описании поля переименовывает параметр запроса.
- Статистика приходит с `/api/v1/stats/:section` и рендерится в `#stat-strip`.
- Языки RU/EN переключаются в шапке; подписи — в `I18N`, `COLUMN_LABELS`,
  `NAV_LABELS`, `NAV_GROUP_LABELS`.
- Сборка не нужна: правки `ui/public/*` подхватываются перезагрузкой страницы
  (Ctrl+F5); для правок `server/src/*` нужна пересборка образа API.
