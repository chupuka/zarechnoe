# Архитектура и схемы интерфейсов

> ИС «Заречное» (Вариант 11), Неделя 7.

## 1. Схема архитектуры

См. [tech_doc.md](tech_doc.md) п.2. Три процесса: `db` (PostgreSQL+PostGIS),
`api` (ядро, Express), `reports` (микросервис аналитики). Клиент — SPA без сборщика.

## 2. Схема микросервисов

| Сервис | Порт | Ответственность | Права БД | Пул |
|---|---:|---|---|---:|
| `api` | 3000 | Бизнес-логика, запись, RBAC, аудит, раздача UI | чтение/запись (DML) | 10 |
| `reports` | 4000 | Только чтение, тяжёлые агрегации, `/aggregate` | чтение | 4 |
| `db` | 5433 | Единая точка истины, триггеры, процедуры | — | — |

Взаимодействие: `api` → `reports` по HTTP с тем же Bearer-токеном;
`reports` сам проверяет токен через `user_session` и право `report:READ`.
Отказ сервиса → `503` с понятным сообщением (не тихий fallback).

## 3. Схема интерфейсов (навигация)

```
/app/                       ← точка входа (index.html)
├── Вход ( login → sessionStorage token )
├── Шапка: логотип · пользователь · роль · тема · RU/EN · выход
├── Боковое меню (пункты скрываются по data-permission):
│   ├── Реестры
│   │   ├── Животные        /animals          [animal:READ]
│   │   ├── Группы          /animal-groups    [group:READ]
│   │   ├── Осмотры         /examinations     [health:READ]
│   │   ├── Вакцинации      /vaccinations     [health:READ]
│   │   ├── Склад           /stock            [stock:READ]
│   │   ├── Участки         /pasture-plots    [pasture:READ]
│   │   ├── Задачи          /tasks            [task:READ]
│   │   └── Сотрудники      /employees        [employee:READ]
│   ├── Операции
│   │   ├── Выпас           /grazing          [pasture:READ] + карта OSM
│   │   └── Движения склада /stock/movements  [stock:READ]
│   ├── Аналитика
│   │   ├── Дашборд         /reports/dashboard        [report:READ]
│   │   ├── Себестоимость   /reports/cost-fcr
│   │   ├── Здоровье        /reports/herd-health
│   │   ├── Пастбища        /reports/pasture-load
│   │   ├── Задачи в работе /reports/tasks-in-work
│   │   └── Остатки         /reports/stock-turnover
│   ├── Администрирование   [user:READ]
│   │   ├── Пользователи    /admin/users
│   │   ├── Роли и права    /admin/roles
│   │   ├── Журнал аудита   /admin/audit-log   (+ CSV)
│   │   └── Настройки       /admin/settings
│   └── Технадминка         [tech:READ] — физически отдельный раздел
│       ├── Резервные копии /tech/backups
│       ├── Восстановления  /tech/restores
│       ├── Тех. лог        /tech/log
│       └── Метрики         /tech/metrics
└── Модалки: создание/редактирование · подтверждение удаления ·
             перевод группы на участок · справка по hotkeys
```

Клиентская «скрыть пункт меню» — только удобство: сервер всё равно проверяет
право на каждый запрос (`middleware/rbac.js`), отказ → 403 + `DENY`.

## 4. Экран «Выпас» (по образцу Farmbrite)

| Участок | Площадь, га | Группа | Голов | Дней на участке | Действие |
|---|---:|---|---:|---:|---|
| P-01 | 8.74 | КРС-1 | 23 | 4 | «Перевести» → `POST /grazing/move` |

Рядом — карта: полигоны участков на подложке OSM, цвет по статусу
(зелёный — отдохнул, жёлтый — период отдыха не завершён, красный — перегрузка),
попап с площадью и текущей группой, легенда.

## 5. Горячие клавиши (≥8)

| Клавиша | Действие | Где |
|---|---|---|
| `Ctrl+K` | Глобальный поиск | везде |
| `?` | Справка | везде |
| `I` | Приход корма | Склад |
| `O` | Расход корма | Склад |
| `W` | Списание | Склад |
| `A` | Назначить исполнителя | Задачи |
| `D` | Отметить выполненной | Задачи |
| `/` | Фокус в поиск | Реестры |
| `N` | Новая карточка | Животные |
| `Escape` | Закрыть модалку | везде |

## 6. Брендбук

| Элемент | Значение |
|---|---|
| Палитра | `#2E7D32` зелёный, `#1B5E20` тёмно-зелёный, `#F5F1E6` песочный, `#FFFFFF` белый, `#FF8F00` акцент |
| Шрифт | system / Inter, 14–16px base, интерлиньяж 1.5 |
| Сетка/отступы | 8px baseline (8/16/24/32) |
| Радиусы | 8px (карточки, кнопки, инпуты) |
| Иконки | Unicode/Lucide-подобные, без внешних спрайтов |
| Логотип/фавикон | текстовый «Заречное» + эмблема колоса (inline SVG) |
| Компоненты | KPI-карточка, таблица реестра, фильтр-панель, модалка, тост, бейдж статуса |

## 7. Адаптивность (≥3 брейкпоинта)

| Ширина | Поведение |
|---|---|
| > 1200px | Полное боковое меню, 4 KPI в ряд |
| 900–1200px | Свёрнутое меню (иконки), 2 KPI в ряд |
| 600–900px | Меню-drawer, таблицы с горизонтальной прокруткой |
| < 600px | Карточки вместо таблиц, компактная шапка, 1 KPI в ряд |

Дополнительно: светлая/тёмная тема (`data-theme`), RU/EN, `prefers-reduced-motion`,
фокус-стили для доступности.

## 8. Настройки пользователя (на сервере)

`farm_settings` (тема, язык, формат даты, дефолтные фильтры) + `saved_filter`
(сохранённые фильтры реестров). Изменяются через `PATCH /admin/settings/:key`.
