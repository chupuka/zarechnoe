# AGENTS.md — ИС «Заречное»

## Главное правило

Дизайн интерфейса регулируется **`docs/DESIGN.md`**. Продукт и сценарии описаны в **`docs/PRODUCT.md`**. При любом визуальном изменении сначала читать DESIGN.md.

**Массовое удаление декора или анимаций ЗАПРЕЩЕНО.** Прецедент: предыдущий агент удалил ~450 строк декора — владелец откатил. Работать хирургически: токены и точечные правки, каждое изменение с обоснованием в `docs/DESIGN.md` → раздел «Журнал редизайна» (что / почему / файл:строка / коммит).

## Что можно менять

- `ui/public/index.html`, `ui/public/styles.css`, `ui/public/app.js`
- новые `docs/DESIGN.md`, `docs/PRODUCT.md`, `AGENTS.md`
- новый `scripts/design_audit.py` (контраст/слоп-чекер, только чтение)

## Что трогать нельзя

`server/`, `services/`, `db/`, `docker-compose.yml`, `.github/workflows/`, `deploy-config.js`, VPS, контейнеры, порты, ufw, Supabase. Word-документы и **`docs/*.md`, которые уже существуют**, не редактировать (только создавать новые файлы).

## Технические ограничения

- Без фреймворков, сборщиков, npm-зависимостей в UI и внешних CDN для иконок/шрифтов. Иконки и шрифты — локально. Демо должно работать без сторонних сетей (исключение — карта OSM, см. известные ограничения в DESIGN.md).
- Не менять бизнес-логику, роутинг, API-контракты, словари RU/EN (кроме явного копирайтинг-слопа в UI-строках).
- Не переименовывать id/classes/data-атрибуты без `grep` по `app.js` (шаблоны генерируются строками) и обновления всех использований.
- Сохранить: RBAC-меню по permissions, палитру `Ctrl+K`, хоткеи `N/E/B/R`, сохранённые фильтры, RU/EN, переключатель тем, FAB, уведомления, панель «Статус системы», скелеты, view transitions, reveal, параллакс (ограничить), счётчики, карту Leaflet, donut/bars/KPI, canvas-графики, пагинацию, модалки с `X-Override-Reason`, справку по ролям, демо-сценарий.

## Процесс

- Работа в ветке `design/systematize`. Атомарные коммиты `design: …` по логическим шагам.
- Каждый коммит проверен в браузере **до push**. Ноль ошибок в консоли.
- Откат — `git revert` конкретного коммита, **не** `reset`.
- Фаза 0 заканчивается стоп-точкой: показать владельцу DESIGN.md, план и список «что будет удалено». Продолжать только после подтверждения.
- Push в ветку — только после зелёной QA. PR с отчётом. В `main` не мержить без решения владельца.

## Демо-безопасность

Не выполнять разрушающие операции: restore бэкапов, apply/rollback миграций, удаления, блокировки. Проверка — преимущественно чтение; создание/редактирование — только на демо-записях.

## Полезные команды

```powershell
cd WEB_Ferma
git status --short --branch
py scripts/design_audit.py      # контраст, токены, иконки, сlop — только чтение
```
